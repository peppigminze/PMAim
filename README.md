# PMAim

Aimtrainer für Valorant – läuft komplett im Browser (eine HTML-Datei, Three.js via CDN).

- Modi: Gridshot, Flick, Microflick, Tracking, Headshot-Bots
- Valorant-Sensitivität (0,07° pro Count), eDPI & cm/360°-Rechner, FOV 103°
- Anpassbares Fadenkreuz, Highscores (lokal im Browser)

## Starten
`index.html` im Browser öffnen (für Pointer Lock am besten über einen lokalen Server oder GitHub Pages).

Steuerung: Esc = Pause, R = Neustart.
